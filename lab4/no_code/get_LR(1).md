# 生成LR(1)分析表


1. 构建文法数组$S$，构建状态集合数组$Sets$，构建未阅读Set栈STnotRead

2. 循环
    - 初始化：一个<<符号,超前查看符号>,set>集合SignSets
    - 取STnotRead的栈顶Set，STop
        - 查出STop的编号n1
        - 对STop的每一个项
            - sign为点后的第一个符号
            - 如果点已经到达尾部
                - 由超前查看符号决定规约文法号
            - 如果点未到达尾部
                - 如果号,超前查看符号>在SignSets中不存在，就**创建一个set**，存在就直接查出<<符号,超前查看符号>,set>中的set
                - 如果这个符号是终结符号
                    - set∪{点向后移动一位的这个项}
                - 如果这个符号是非终结符号
                    - set∪{这个非终结符号的闭包}
                - 将更新后的set写入SignSets
        - 在Sets中查找SignSets的每一项
            - 如果查到了，无事发生
            - 如果没查到，set加入Sets，set加入未阅读栈STnotRead
        - 遍历SignSets的每一项
            - 查出set的编号n2
                - 若set的<符号,超前查看符号>的sign是非终结符，在(n1,sign)的位置写入s(n2)
                - 若set的<符号,超前查看符号>的sign是终结符，在(n1,sign)的位置写入g(n2)

3. 如何创建一个set
    - 查出由符号sign导出的所有文法
    - 每个文法单独做一项
    - 每项的点置为开始位置
