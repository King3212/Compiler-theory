# 如何生成LALR1DFA

## 如何生成LR1的DFA

1. 为了避免有多个开端，首先生成一个虚拟文法`S'`，文法`S'`指向第一条文法的开始符号

2. 将虚拟文法`S'`放进文法中，初始化第一个状态`(Statu)`，编号为0，将虚拟文法`S'`作为一个项目`(Item)`放入状态0中

   ```c++
   struct Item{
       int grammar;
       int dot;
       bool is_epsilon;
   }
   
   struct Statu{
       IndexedSet<Item
   }
   ```

   

2. 查找

3. 函数`genDFA(int statuIndex)`从任意状态开始进行下面的操作：

   1. 获取当前项目：`stautIndex -> Statu`
   
   2. 找出规约项
      - 如果dot指向了文法末尾
        - 创建规约边
          （当前状态编号，规约文法，元素）
        - 如何查找超前查看元素集合：
          - 在文法列表中查找当前规约项后面所跟的所有符号
          - 如果是非终结符，取它的FIRST集合元素加入超前查看元素集合
            - 如果非终结符是空串，一直取下一个加入超前查看元素集合，直到终结符或者文法结束
            - 如果到了文法末尾，则查找
          - 如果是终结符，取它本身加入超前查看元素集合
   
   3. 生成跳转集合`set genJumpSet(Statu statu)`
      - 遍历状态中所有的项目，找出所有可能的跳转
        跳过到达文法末尾的项
   
   4. 遍历跳转集合
      - 对任意一个跳转：
        - 找出状态中所有符合条件的项目
        
        - 创建新`Statu`
        
        - 将符合条件的项目复制到新`Statu`中
        
        - 新项目集合`dot +1`
        
        - 闭包`closure(Statu statu)`
        
          - 维护一个已搜索集合（初始为空），再次搜索标记（false）
          - 遍历已有项目dot指向的符号
            - 如果是非终结符，查看已搜索集合中有没有，如果没有就添加进去，在文法集合中搜索对应的文法，再次搜索标记 = （true）
            - 如果再次搜索标记为true，再次遍历
        
        - 将`Statu`添加到状态集合中，得到状态编号，判断是否为新状态集合
        
          - 如果是非终结符，添加`goto`边
        
            (非终结符，当前项目编号，目标状态编号)
        
          - 如果是终结符，添加`shift`边
        
            (非终结符，当前项目编号，目标状态编号)
        
          - 如果是新状态集合，递归调用`genDFA(新状态编号)`
