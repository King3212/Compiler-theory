# 程序使用说明书

## 界面使用

1. 保存文法文件：点击保存文法文件，在打开的文件资源管理器中选择保存文件的目录  
2. 打开文法文件：点击打开文法文件，在打开的文件资源管理器中选择你需要打开的文件；  
                 若先前有文法存在于编辑框，则会弹出提示保存文法文件。  
3. 查看所需的DFA和表格：需要在点击“生成”之后，DFA、表格才进入可查看状态；  
                        若对文法进行了修改，则DFA、表格进入锁定状态，需要重新点击“生成”才能查看。  

## 文法输入规则

1. 终结符与终结符之间，终结符与非终结符之间，非终结符与非终结符之间需要用空格间隔  
2. 符号与表示选择的“|”之间必须有空格间隔，否则“|”连同前后的符号，视为一个终结符或非终结符处理  
3. “|”的作用域从上一个“|”或->处开始，到“|”或结尾处结束；与前一个“|”并列，无优先级处理  
4. 只识别“|”一个符号，其他处理请通过修改文法来实现
