# EBNF中TINY语言的文法

program $\rightarrow$ stmt-sequence  
stmt-sequence $\rightarrow$ statemnet { **;** statement } | [ **;** ]
statement $\rightarrow$ if-stmt | repeat-stmt | assign-stmt | read-stmt | write-stmt | while-stmt | for-stmt
if-stmt $\rightarrow$ **if (** exp **)** stmt-sequence [**else** stmt-sequence] **;**
repeat-stmt $\rightarrow$ **repeat** stmt-sequence **until** exp
assign-stmt $\rightarrow$ normal-assign | re-assign
read-stmt $\rightarrow$ **read** **identifier**
write-stmt $\rightarrow$ **write** exp
while-stmt $\rightarrow$ **while** **(** exp **)** stmt-sequence **endwhile**
for-stmt $\rightarrow$ **for** **(** assign-stmt **;** exp **;** exp **)** stmt-sequence **;**
normal-assign $\rightarrow$ identifier **:=** exp
re-assign = identifier **==** re-exp
exp $\rightarrow$ simple-exp [comparison-op simple-exp]
comparison-op $\rightarrow$ **<** | **>** | **<>** | **<=** | **>=** | **=**
simple-exp $\rightarrow$ term [addop term]
addop $\rightarrow$ **+** | **-**
term $\rightarrow$ power-exp [mul-op power-exp]
mul-op $\rightarrow$ **\*** | **/** | **%**
power-exp $\rightarrow$ factor [**^** factor]
factor $\rightarrow$ **(** exp **)** | **number** | [increase-op] **identifier**
increase-op $\rightarrow$ **++** | **--**
re-exp $\rightarrow$ simple-re-exp { **|** simple-re-exp }
simple-re-exp $\rightarrow$ closure { [ **&** ] closure }
closure $\rightarrow$ re-fector [ closure-op ]
closure-op $\rightarrow$ **#** | **?**
re-fector = re-ele | **(** re-exp **)**
re-ele $\rightarrow$ **number** | **identifier** {**number** | **identifier**}
